# 打磨循环

## Purpose
把一份产出物经「生成 → 评判 → 修正」闭环磨到成文标准的子循环。
当用户说"打磨两轮"、"按标准过一遍"，或 pipeline 内环需要"修→验→回修"时，用本 skill。
完整版 spec：`../specs/REFINE_LOOP_SPEC.md`（v1.0）。

## 形状
初版产出 → 按标准评判 → 达标通过；不达标带意见回炉（计数+1），超 3 次升级。

## 五条硬规则
1. 标准前置且可执行（检查表/打分线），无成文标准不开磨。
2. 写判分离：生成者不判自己。
3. 打回必须带意见：哪条不行、怎么改。
4. 退出三选一：达标 / 超 3 次升级 / 人工叫停。
5. 升级附历次评判意见与修改 diff。

## 标准库
- 代码：fuzz 干净 + CI 绿 + diff 覆盖 100%
- X 帖子：「有意义」标准 + ≤280 字符 + 口径纪律
- 文档：结论先行 + 数据可溯源 + 一页纸摘要
- QA：AC 全过 / fuzz 干净

## 失败处理
无标准→先定标准；写判同一人→重判；打回无意见→退回补意见；超 3 次→升级；人工叫停→停。
